Kommandozentrale

Eine Bühne, beliebig viele Module. Jedes Modul ist eine eigene HTML — du arbeitest weiter nur an der, die du brauchst, NEXUS bindet sie ein. Unten das Terminal (Taste `).

nexus-shell · ops@nexus — `help` für Befehle✕
ops@nexus:~$

Modul andocken

Eine HTML-Datei = ein Modul.
Leg die HTML in denselben Ordner wie NEXUS (oder gib eine URL an). Dann lädt NEXUS sie ins Hauptfenster — du kannst sie weiter unabhängig bearbeiten.
